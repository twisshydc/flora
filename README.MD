This is our web app Flora! It is a browser-based plant tracking application designed mainly for beginner plant owners, home gardeners, and plant enthusiasts who need a simple way to organize and monitor their plants.

Its core purpose is to provide one place where users can create and manage plant records, view important care information, search and filter their collection, and keep track of simple plant-care activities. The application uses HTML, CSS, and JavaScript for its frontend, with Node.js and Express.js providing backend support. User accounts, plant records, and care reminders are stored and managed through JSON files, allowing data to persist beyond browser sessions.


To run it our web app type node server.js
